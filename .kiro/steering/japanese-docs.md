# ドキュメントは日本語で書く

- ユーザーが読むドキュメント（requirements.md、design.md、tasks.md、bugfix.md、README、各種説明文）は、すべて日本語で書く。
- Kiro Specのフォーマット検証に必要な構文キーワード（EARSの WHEN / WHILE / WHERE / IF / THEN / THE / SHALL など）は英語のままでよい。それ以外の文章は日本語にする。
- コード識別子、API名、ファイルパス、CLIコマンド、システム名（Navi_App など）、固有名詞（hachioji-gov）は翻訳しない。
- コード内のコメントも日本語で書く。
- アプリ名称は「hachioji-gov」とする。
